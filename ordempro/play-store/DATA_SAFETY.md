# Declaração de segurança dos dados

Preencha o formulário do Play Console conforme a versão atual deste projeto:

- O aplicativo coleta ou compartilha dados do usuário? **Não.**
- O aplicativo contém anúncios? **Não.**
- Há conta de usuário? **Não.**
- Há criptografia de dados em trânsito? **Não aplicável**, pois o app não transmite dados.
- Há opção de exclusão? **Sim.** Cada ordem pode ser excluída pelo usuário e todos os dados locais são apagados ao desinstalar o app.

Os dados de profissional, cliente e ordem de serviço ficam somente no armazenamento privado do dispositivo. O compartilhamento do PDF acontece apenas quando o próprio usuário seleciona outro aplicativo no seletor do Android.

Revise estas respostas sempre que forem adicionados anúncios, análise de uso, backup em nuvem, login ou qualquer SDK externo.
